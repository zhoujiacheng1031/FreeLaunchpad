# 点击区域检查（1.8.2）

日期：2026-10-14。范围：工作组切换、成员勾选、页面侧栏、预览图标及工具栏的同类点击区域。

| 控件 | 检查结果与处理 |
| --- | --- |
| 工作组列表 | 原先未选行的留白无法切换；在完整标签布局后添加点击形状，整行可切换。 |
| 工作组成员复选框 | 标签扩展到整行宽度，将留白和内边距包含进点击区域；保留原生复选框语义。 |
| 页面预览卡片 | 点击形状覆盖完整单元格，包含图标与文字以外的空白；保留拖动和布局锁定规则。 |
| 玻璃工具按钮 | 在共享玻璃修饰符中声明与可见圆角形状一致的交互区域；页面管理、工作组、锁定和设置共用。 |
| 页面管理侧栏 | 已有完整行的矩形点击区域，无需修改。 |
| 普通系统按钮、菜单和设置动作 | 保留原生控件行为。仅展示状态的成员结果卡片保持展示用途。 |

真实界面验收：旧版点击未选工作组右侧留白无变化；新版同一位置可切换，两个组来回切换成功。成员行右侧留白点击将已选数量加一，再点恢复；取消编辑后未保存临时勾选。页面预览卡片空白边缘能勾选、取消；页面侧栏留白切换成功；工作组玻璃按钮图标下方的空白点击打开工作组窗口。

完整布局 JSON 与本轮开始时基线相等，工作组名称、成员和图标布局未改变。本轮没有启动、退出成员应用或创建系统桌面。

后续界面改动的手动回归：用包含长名称和至少两个工作组的布局，依次点击未选行右侧、上／下内边距、图标及文字，确认详情和高亮切换；检查成员行勾选与取消、预览卡片边缘勾选、侧栏空白切页、工具按钮空白点击。系统禁用动作仍不可执行。结构检查和模型单元测试不能代替此点击验收。

使用项目经验 K-001，从用户反馈的工作组行扩展检查同类控件；K-002 用于保留可重复的点击验收步骤。
