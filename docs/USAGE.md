# 使用指南

- 菜单栏九宫格图标 → 打开 FreeLaunchpad。
- **Control + Option + 空格**：全局显示 / 隐藏。
- 输入应用名、完整拼音或 bundle ID 搜索；回车打开首个结果。
- 方向键选择，回车打开；Page Up / Page Down、页面圆点、双指滚动翻页。
- Esc 按顺序清除搜索、返回文件夹、关闭启动台。
- 拖到图标中心创建文件夹或加入现有文件夹；文件夹互相叠加会合并内容。无需按 Option。拖到空位自由摆放并对齐不可见网格，原位置保持留空；拖到已有图标名称处交换位置，文件夹内同样支持。
- 拖到分页按钮可移动到该页；拖动时停留在分页按钮或屏幕左右边缘约 0.65 秒会翻页，之后可继续选择落点。右键 → 移到页面也可指定目标页。分页栏的“＋”可添加空白页，放入图标后会随布局保存。
- **页面管理（Command + L）**：搜索框旁九宫格按钮、菜单或设置均可进入。页面以启动台相同的行列、间距与位置显示，空位保留并用虚线标出。按来源页筛选，搜索名称 / 拼音，点击图标勾选或“全选当前列表”，选择目标页后一次移动。跨来源页和搜索筛选保留勾选；目标页已有图标保持位置，移入项按原顺序填入空位，来源位置留空。空间不足时提示新建空白页或减少选择。可管理整个文件夹的位置，也可选择文件夹范围整理其内部页面。
- **批量应用操作**：在页面管理中勾选应用，点击“启动所选”或“退出所选”。跨页和搜索筛选保留选择；选择文件夹会按其内部网格顺序包含所有成员。布局锁定不影响这两个操作。启动跳过已经运行的应用；退出使用正常退出方式，逐个显示已退出、未运行、等待保存或失败，不强制结束进程。Finder、Dock、FreeLaunchpad 自身等系统组件保留。
- **桌面工作组（Command + G）**：启动台搜索栏旁三个矩形按钮、菜单或页面管理均可进入。选择多个应用后命名并保存，之后可编辑名称和成员、批量启动或退出。工作组独立记录成员名单，不会改变启动台图标的位置或创建启动台文件夹。应用临时不可用时保留成员，重新安装或重新扫描后可继续使用；工作组随布局备份和重启保留。
- **新建桌面并归入应用（试用）**：在工作组内点击主按钮，创建一个新的 macOS Space，切换到它，启动未运行的成员，然后尝试把成员的普通窗口集中到该桌面。首次使用需在系统设置 → 隐私与安全性 → 辅助功能中启用 FreeLaunchpad（本机 macOS 27 对应页面名为“设备控制和数据访问”）。“辅助功能设置…”可打开对应系统页面。缺少权限或新建失败时停止，不启动或搬移应用；单个应用或窗口失败时继续处理其他成员并显示具体结果。每次点击创建一个新桌面，暂不保存桌面 ID 或自动复用旧桌面；工作组名称不会改写系统桌面名称。退出工作组应用不会删除桌面。
- **页面网格调整**：管理页内直接拖到空位移动，拖到已有图标交换位置，可撤销最近一次移动 / 交换；文件夹内部同样支持。右键文件夹 →“管理文件夹内页面”，或使用顶部管理范围切换。选择“全部页面”按页纵向预览，根页面和文件夹页面共用启动台的网格计算并避开 Dock。每页“查看”直接打开对应启动台页面。筛选仅隐藏无关图标，保持原行列和空位；跨页大量移动仍可用底部批量操作。
- **只看已选**：集中核对所有页面的勾选项，支持继续搜索和取消勾选。进入时清除搜索条件，点击来源页退出；当前列表之外的选择会提示数量，移动时一起处理。页面管理支持 Command + F 聚焦搜索、Command + Shift + A 全选当前列表、Command + Return 移动；Esc 依次清除搜索、退出已选核对、关闭窗口。窗口已打开时再次按 Command + L 会保留勾选、搜索和撤销记录。
- **批量整理到文件夹**：在“所有应用”管理范围跨页勾选，点击左侧“整理到文件夹…”。新建至少需要两个图标；移入现有文件夹可选择一个或多个图标。新文件夹位于所选图标最靠前的原位置，其他源位置留空；移入现有文件夹保留其根位置、名称与内部空位，追加新成员。所选文件夹合并内容，不产生嵌套。确认面板显示图标数、应用数和放置方式，新文件夹名称限 1–40 个字符。
- **页面命名**：点击目标页旁铅笔按钮，或右键来源页 → “命名这一页…”。根页面与文件夹内页面分别命名，名称最多 40 个字符，留空恢复默认页码。名称显示在启动台分页、来源列表、目标页和图标说明中；命名的空白页会保留。名称对应页码，调整网格行列数后仍跟随该页码。
- 页面管理内可撤销最近一次批量移动、建组或移入文件夹，保留其他外观设置。建组 / 移入的撤销恢复原文件夹、内部空位和文件夹页名称，保留之后修改的根页面名称；后续图标或文件夹结构、内部页名称变化时拒绝撤销。批量移动的撤销会检查原位置占用和移动项是否改变。退出管理窗口后重新打开或切换管理范围会清除撤销记录。点击“在启动台查看”可返回对应页面。
- **锁定布局**：启动台搜索框旁锁按钮、页面管理顶部按钮、菜单或设置均可切换。锁定后可浏览、打开、搜索应用，图标大小、间距与背景仍可调整；拖动、交换、建组、隐藏 / 恢复应用、文件夹重命名 / 解散、页面命名和网格行列数不可修改。新安装应用仍会自动加入，卸载应用会从扫描结果中移除。锁定会取消正在进行的拖动，拖动手势不会误触发打开。锁定状态重启后保留；恢复备份会采用备份中的锁定状态。
- 右键菜单也可以创建 / 加入文件夹、重命名 / 解散文件夹、隐藏应用、在 Finder 显示。
- 设置 → 应用：恢复隐藏的应用、增加外部应用目录。
- 设置 → 外观与启动：行列数、图标大小、横向 / 纵向图标间距、背景来源、不透明度、壁纸模糊、触发角、登录启动。默认图标 88 pt，可调范围 40–128 pt；网格过密时会按可用空间缩小。旧版 64 pt 默认值会一次升级为 88 pt，自定义大小保留。
- 设置 → 外观与启动 → Dock：开启“启动台打开时隐藏 Dock”。关闭启动台、打开应用、进入设置或退出程序时恢复原状态。关闭此选项时沿用系统 Dock 设置，内容自动避开底部 / 左侧 / 右侧 Dock；适配系统自动隐藏与多屏可用区域。
- 设置 → 备份与关于：导出 / 恢复布局。恢复前保存 `before-restore.json`。

扫描目录为 `/Applications`、`~/Applications`、`/System/Applications` 和用户添加的目录，另外收录 Finder。应用包内的嵌套帮助程序和 `LSBackgroundOnly` 后台程序不会显示。每 60 秒以及唤醒后重新扫描。

图标区域默认按可用屏幕宽度展开（通常约 93%），行高使用搜索栏与分页之间的全部空间。横向、纵向间距可分别从 0% 紧凑调整到 100% 铺满，网格保持居中，始终留出图标和名称所需间隙；“重置间距”恢复 100%。调整间距不改变图标所属页、行列序号或每页容量。布局格式为 v5，包含位置、空位、页面名称、锁定状态、间距和桌面工作组；v1 / v2 / v3 / v4 布局与备份自动迁移，保留原位置与设置，旧版默认间距 100%。旧版 FreeLaunchpad 不支持读取 v5 布局。

启动台显示明确页码，空白页提供“打开页面管理”入口，搜索无结果时可以直接清除搜索。页面管理的搜索、来源页和操作栏使用统一玻璃控件，网格预览随窗口缩放，行列数与启动台一致，切换页面或筛选时回到顶部；选中项同时显示勾选标记与边框。预览中的名称为单行缩略，悬停可查看完整名称。共享控件适配浅色 / 深色及系统“降低透明度”。

数据存储在 `~/Library/Application Support/FreeLaunchpad/`，与原应用的数据独立。应用不包含联网接口、遥测、账户或付费限制。运行时读取系统和本机应用图标，分发包没有复制 BuhoLaunchpad 的代码、图标、素材或资源。

背景可以选择“当前桌面”“桌面壁纸”或“自定义图片”。不透明度从 0% 到 100%：越低越能看见后方桌面和窗口，图标 / 文字不跟随背景变透明。当前桌面模式使用可调暗色遮罩直接透出窗口；壁纸 / 图片模式可单独调节模糊。在系统开启“降低透明度”时会使用不透明背景。桌面壁纸优先由 NSWorkspace 读取，失败时尝试当前显示器的本机壁纸配置；不截图、不申请录屏权限。备用配置结构可能随系统更新改变，读取失败会在设置内提示。

macOS 26 及更新版本使用 Apple 原生 Liquid Glass，应用于搜索、设置、文件夹预览和分页控件；旧系统使用半透明材质。界面支持悬停 / 按压反馈、系统“减少动态效果”和“降低透明度”。Dock 隐藏使用当前应用的 AppKit presentation options，不改系统 Dock 偏好。旧布局与备份缺少 Dock 字段时默认沿用系统设置。
