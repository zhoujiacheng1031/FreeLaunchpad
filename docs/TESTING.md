# 验证说明

版本：1.8.1 build 10。验收日期：2026-10-12。

`bash test.sh` 通过 259 项回归检查，覆盖布局迁移与持久化、文件夹与跨页移动、批量选择、撤销冲突、保存失败回滚、Dock 可用区域、透明度与壁纸、锁定、应用生命周期、工作组，以及桌面失败时停止或继续处理的边界。

桌面兼容性检查使用从实际控件结构归纳的 Dock 与 WindowManager 层次，验证空 mc 根、显示器匹配，以及异步窗口移动的延迟归属、超时和多桌面情况。这些自动检查不能替代系统实测。

macOS 27.0.1 / Apple Silicon 实际验收：

1. 新建并切换 macOS Space，启动计算器和时钟，两者各一个普通窗口确认在目标桌面。
2. 对已运行的同两款应用再创建目标桌面，将普通窗口移入；每项成功均读取 `SLSCopySpacesForWindows` 确认单一目标归属。
3. 过滤无桌面归属的临时窗口，避免系统切换过程中的临时界面造成多余失败提示。
4. 通过工作组正常退出，确认两款应用已退出。
5. 删除临时工作组后，与验收前的完整布局 JSON 比较相等。
6. 分发 ZIP 解压副本及安装副本通过严格签名校验，二进制内容相同。

测试产生的空桌面保留，需在系统调度中心关闭。其他 macOS 版本、Intel、多显示器实机、全屏和固定桌面窗口不在本次成功验收范围内。系统接口动态探测，缺失或归属无法确认时报告失败。
